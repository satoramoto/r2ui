# r2ui 0.3: what agentmon taught us

agentmon (a macOS agent monitor built on r2ui's dashboard DSL and CLI toolkit) is r2ui's first
real customer. Its defect reports are `agentmon/r2ui-feedback.md` (items F1–F17), the friction lines
from its story PRs (P1–P40, deduplicated below), and two things seen in its real frame (X1, X2).
This file triages every item once: **core** (changed in this design PR, because it touches shared
files), **story** (new files only, listed under Stories), or **declined** (with the reason).
Duplicates point at the item they repeat.

Counts: 59 reports (17 + 40 + 2) → 46 distinct items: **29 fixed in core**, **6 left to
stories** (7 stories: v01-detail adds a convenience on top of core fix F6), **11 declined**.
Nothing reported was already fixed on `main` (bba63f4).

## Triage

### Composition and data

| Id | Report | Verdict |
|---|---|---|
| F1 | A dashboard can't be assembled from several files; `add_dashboard` replaces by name | **Core.** Named rows (`row :top, height: 14 do ... end`; `order:` on rows and panels), `R2UI.dashboard(name, extend: true)` runs another block on the same builder, and `R2UI.panel :memory, row: :top, order: 10 do ... end` adds one panel from any file. Extensions apply in either load order. A row with no panels takes no space. |
| F2 | Resources can't be extended; redefinition silently replaces | **Core.** `R2UI.resource(:process, extend: true) { action ... }` (either load order). Defining a resource, dashboard or source twice from two places raises with both locations; `replace: true` means it; defining it again from the same place (a file `load`ed twice) replaces itself, keeping other files' extensions. A block that raises leaves the registry unchanged. |
| F3 | No shared or derived sources; three panels sample three times | **Core.** `R2UI.source(:sample, every: 2) { \|previous\| ... }` + `source(from: :sample) { \|s\| s[:processes] }`. One cache per app (`R2UI::Sources`): fetched at most once per interval however many feeds read it; the block gets the previous value (for rates); errors are cached for the same window and show on every feed; a feed without `refresh every:` follows its source's interval; `refresh` (s19) expires the cache. |
| F4 | CLI `dashboard` only knows the global registry; snapshots take 1 tick | **Core.** `dashboard(name, registry:, ticks:)`. |
| F7 | History fixed at 120 points; a row that disappears loses its sparkline; no app-computed series | **Core.** `refresh every: 2, history: 900`; a series whose row disappears is kept for `history` samples, so a row that comes back continues its line; `column :p, sparkline: :trend` (or a lambda) and `sparkline :pressure, series: :pressure_trend` plot a series the row/record carries. Also fixed: grouped sparklines summed a shorter series wrongly (a negative index wrapped). |
| F15 | Panel item blocks can't take arguments (agentmon wrapped them to pass its engine) | **Declined.** With `R2UI.panel` and shared sources the wrapper has no reason to exist: blocks close over locals, and data comes from sources. |
| F17 | `R2UI.reset!` drops resources defined at require time | **Core.** `R2UI.with_registry { load "ui.rb" }` loads definitions into a fresh registry (returned) without touching the global one; `App.new(registry)` and `dashboard(registry:)` take it. |
| P16 | A `view` block can't reach its panel's record | **Core.** While a panel item draws, the Context has `rows` and `record`. |
| P24 | A column reader gets only the row (no feed time for "3m ago") | **Declined.** The `:age` format (X2) renders a Time relative to now, and sorts by the Time. |

## Core contract changes in this PR

All backward compatible except the two breaking changes below. Files: `lib/r2ui.rb`,
`registry.rb`, new `source.rb`, `dsl/dashboard.rb`, `dsl/resource.rb`, `dsl/column.rb`, `feed.rb`,
`history.rb`, `format.rb`, `query.rb`, `app.rb`, `renderer.rb`, `context.rb`, `component.rb`,
`widgets/table.rb`, `ext/help.rb`, `ext/refresh.rb`, and on the CLI side `cli/{shell,testing,help,
definition,runner,context,extension}.rb` and `cli/ext/{table,dashboard,completion,format}.rb`.
The DSL is in `docs/dsl.md` ("Composing an app"), the CLI in `docs/cli.md`.

**Breaking changes (intentional):**
- Defining a resource, dashboard or source with the same name from a *different* place now raises
  instead of silently replacing (that was F2's bug). Pass `replace: true` to replace on purpose.
  `Registry#add_resource`/`#add_dashboard` (built objects) still replace silently.
- Action handlers run on a Context (`instance_exec`), so inside one `self` is the Context, not the
  object that defined the resource. A handler that called a private method of its defining object
  must call it through a local (`me = self; action(...) { |row| me.send(...) }`).
- A per-row action no longer stops at the first failing row.
- Help shows a command's summary above its description when both are set.

names its test class `<Story><Kind>Test`. A missing story never breaks the core.
